# uwu-x-proxy
Manage all AI API endpoints on single web application.  
> Support: **Antigravity**, **Codex**, **API Endpoints**.

## Install
Only 1 command: `npm i uwu-x-proxy`.
Then enter url on your browser: `http://localhost:3081`.

## Features  
- Proxy your others api providers.
- Support login with Antigravity and proxy their models endpoints
- Support login with Codex and proxy their models endpoints.
- Test inference directly before use.
- Auto integrate models to Deepseek Harness.
- Analytics, shown all usage data, requests, ...
