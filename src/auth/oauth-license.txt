OAuth reference attribution

The OAuth authorization/token parameters and temporary callback flows follow:
- antigravity-claude-proxy/src/auth/oauth.js and src/webui/index.js
- codex-claude-proxy/src/oauth.js
Google project discovery and onboarding are copied with local dependency adapters.
Intentional differences: strict state checks, loopback-only listeners, await actual
port binding, bounded token requests, no credential logging, and success after save.
Google uses its registered redirect port rather than silently falling back to an
unregistered redirect URI. OpenAI uses the reference 1455-1460 fallback range.

Additional ports: public/oauth.js follows antigravity-claude-proxy/public/js/
components/add-account-modal.js (copy URL and callbackInput completion).
src/auth/codex-import.js adapts codex-claude-proxy/src/account-manager.js
importFromCodex: same auth.json token fields and claim extraction, with encrypted
x-proxy storage instead of reference account files. CODEX_HOME support, input
validation and read-only source handling are local adaptations. Manual URL mode
does not require binding a callback listener; this is an intentional difference.
